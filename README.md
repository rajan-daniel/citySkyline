## 🌆 City Skyline (CSS Variables Project)

### 📌 Preview  
This project is a simple “City Skyline” built using HTML and CSS. It focuses on using CSS variables to create reusable and easily maintainable styles while designing a skyline layout.

---

### 📖 About the Project  
CSS variables (also known as custom properties) allow developers to store values in one place and reuse them throughout a stylesheet. In this project, I built a city skyline while learning how to define, organize, and apply CSS variables to make styling more efficient and scalable.

---

### 🚀 What I Learned  
- How to define and use **CSS variables**  
- Reusing styles efficiently across multiple elements  
- Structuring a visual layout using **HTML and CSS**  
- Improving code readability and maintainability with variables  
- Understanding how CSS can be made more dynamic and flexible  

---

### 🛠️ Technologies Used  
- HTML5  
- CSS3 (CSS Variables / Custom Properties)  

---

### 🎯 Key Takeaway  
This project helped me understand how CSS variables simplify styling and make it easier to manage complex designs like a city skyline.
